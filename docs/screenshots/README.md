# 📸 Screenshots do CodelyFlix

Coloque aqui os prints do projeto, usando esses nomes (o `README.md` principal
já está preparado para exibi-los automaticamente assim que os arquivos existirem):

| Arquivo | O que fotografar |
|---|---|
| `home.png` | Página inicial — banner em destaque + fileiras de filmes/séries |
| `filme.png` | Página de detalhes de um filme (com o player) |
| `player-bloqueado.png` | O cadeado 🔒 aparecendo pra quem não está logado |
| `login.png` | Tela de login/cadastro |
| `admin-dashboard.png` | Painel administrativo — dashboard |
| `admin-cadastro.png` | Tela de cadastro/edição de filme com fontes de vídeo e legendas |
| `app-android.png` | O app instalado e aberto no celular (tela cheia, sem barra do navegador) |

## Dica rápida pra tirar prints bons

- Cadastre 3–4 filmes com posters de verdade antes de fotografar a Home (fica bem mais bonito
  do que a tela vazia)
- No celular, tire o print já com o app instalado como APK, não só o site no navegador
- Prefira resolução 1280×720 ou mais para telas de desktop, e a resolução nativa do
  celular para as telas mobile

Depois de adicionar os arquivos aqui, é só commitar normalmente:
```bash
git add docs/screenshots
git commit -m "docs: adicionar screenshots"
git push
```
